---
name: Brand migration boundaries
description: Why product renames should not automatically rename technical identifiers.
---

Keep legacy package names, directory slugs, and persisted browser storage keys stable when updating user-facing branding.

**Why:** Renaming these identifiers can break workspace build filters, artifact routing, or existing users' saved organization context without improving what users see.

**How to apply:** Update copy, metadata, and visible assets independently. Rename internal identifiers only with an explicit compatibility and migration plan.
