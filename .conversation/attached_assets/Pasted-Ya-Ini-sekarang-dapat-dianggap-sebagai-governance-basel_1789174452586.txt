### Governance rule yang sekarang bersifat final

**`VERIFIED` adalah status berbasis bukti, bukan status berbasis progres implementasi.**

Karena itu:

| Kondisi                            | Status yang sah       |
| ---------------------------------- | --------------------- |
| Implementasi selesai               | `IMPLEMENTATION`      |
| Integrasi selesai                  | `INTEGRATION`         |
| Adversarial test sedang/divalidasi | `ADVERSARIAL TESTING` |
| Regression sedang/divalidasi       | `REGRESSION`          |
| Bukti sedang direview              | `EVIDENCE REVIEW`     |
| Semua gate + evidence lulus        | `VERIFIED`            |
| Sudah terbukti stabil              | `STABLE`              |
| Sudah dikunci                      | `LOCKED`              |
| Salah satu critical gate gagal     | `NOT VERIFIED`        |

Dan **tidak ada shortcut** dari:

`Build PASS → VERIFIED`
`Unit Test PASS → VERIFIED`
`UI PASS → VERIFIED`
`API PASS → VERIFIED`
`Mostly PASS → VERIFIED`
