### Governance aktif Task #04

Boundary yang saya pegang:

1. **Verify first, mutate only if explicitly required**

   * Schema check harus terlebih dahulu membuktikan kondisi aktual.
   * Tidak menganggap migration/schema mutation sebagai langkah otomatis.

2. **Destructive operation = hard stop**

   * `truncate`
   * `DROP`
   * delete/recreate
   * `push --force`
   * destructive migration
   * menjawab prompt migration secara otomatis

3. **Migration journal tetap immutable**

   * Tidak diedit, direkonstruksi, atau diselaraskan secara manual untuk menghilangkan perbedaan.

4. **Constraint protection**

   * Nullable uniqueness tidak boleh dilemahkan hanya agar schema check menjadi PASS.
   * Existing semantics harus dipertahankan.

5. **Drizzle destructive diff**

   * Jika Drizzle mengusulkan operasi destruktif, **STOP**.
   * Laporkan **exact diff/operation** terlebih dahulu.
   * Tidak mengambil keputusan implisit untuk meneruskannya.

6. **Task #02 tetap tertutup**

   * Facility & Space Registry yang sudah `MERGED` tidak dibuka kembali.
   * Hanya regresi yang terbukti dapat menjadi alasan membuka kembali boundary tersebut.
